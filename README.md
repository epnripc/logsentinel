# LogSentinel

Monitor de seguridad para pequeñas empresas: detecta ataques en los logs, una IA los explica en lenguaje humano y se mitigan con un clic.

Proyecto de la 1hack de la UDC (13/11/2026).

## Estructura

- `generator/`: generador de tráfico y ataques simulados
- `frontend/`: dashboard en React + Tailwind (lo crea Vite)
